Getting Started

1. Introduction

DriveEase is a commercial-grade, multi-page HTML5 website template engineered for professional driver on hire agencies, luxury chauffeur services, executive corporate transportation firms, and private mobility startups.

Built strictly using semantic HTML5, CSS3, Tailwind CSS utilities, Bootstrap 5 (v5.3.3), and clean modular Vanilla JavaScript. It requires zero compilation steps, no Node.js backend, no PHP, and no complex framework tooling—making it 100% plug-and-play for buyers on ThemeForest and TemplateMonster.

2. Key Features

24 Complete HTML Pages

2 unique homepages, about, 8 services, pricing, blog, contact, auth, and full 9-page dashboard.

Dynamic Price Engine

Real-time quote calculation based on category, hours, vehicle class, and addons.

Instant Dark & Light Mode

Persisted via localStorage across all main website pages and dashboard views.

Complete RTL / LTR Support

Native support for Arabic and Hebrew layouts with mirrored navigation & sidebars.

LocalStorage Mock Persistence

Saved bookings, profile updates, and demo customer sessions remain intact across pages.

Print-Ready Invoices

Clean @media print styling stripped of navbars for formal expense statements.

5. Dynamic Booking Engine

The booking system in assets/js/booking.js calculates dynamic quotes with:

  • Category Rates: Hourly ($22/hr), Full Day ($135 flat), Luxury Chauffeur ($45/hr), Corporate ($38/hr), Airport ($49 flat), Outstation ($36/hr).
  • Vehicle Multipliers: Sedan ($0), SUV ($20), Luxury Limousine ($45).
  • Add-ons: $12 each for Uniformed Chauffeur, Luggage Handling, Multi-lingual, and Express Toll Pass.
  • Tax Calculation: Automatically computes 8% sales tax and generates a live itemized breakdown.

6. Dark Mode & RTL Switching

Dark mode is toggled via window.toggleDriveEaseTheme() and saved under localStorage key driveease_theme. RTL is toggled via window.toggleDriveEaseRTL() and saved under driveease_dir. Both activate zero-flash styling on load.
